Lentera Pasar Malam — a spot-the-difference game set in an Indonesian night market. Two near-identical pictures side by side, three hand-drawn levels (Satay Cart Street, Lantern Stall, Ferris Wheel Fair) with 7, 8 and 10 differences, a countdown timer, score with streak bonuses, a hint ring on cooldown, and full keyboard play with a reticle.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click a difference on either picture, or steer the reticle with the arrow keys, Tab to switch pictures, Enter to mark, H for a hint, P to pause.
